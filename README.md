# study-everyday

백엔드 학습 아카이브. 목표는 **토스 서버 개발자 수준의 백엔드 엔지니어**.

## 구조

```
study-everyday/
├── auto/          ← 비공개 (gitignore). 초안·커리큘럼·작업 메모
│   ├── 커리큘럼/   ← 과목별 학습 계획. 체크박스로 진행 관리
│   └── 초안/       ← 공부하면서 남기는 날것의 기록
└── docs/          ← 공개. 완성된 글만 승격해서 올린다
```

## 원칙

1. **auto는 마음껏 어지른다.** 틀려도 되고, 반쯤 쓰다 말아도 된다.
2. **docs는 남에게 보여줄 수 있는 것만.** 초안이 정리되면 승격한다.
3. **커리큘럼 체크박스는 "설명할 수 있다"를 기준으로 채운다.** 읽었다 ≠ 체크.
4. 각 과목의 `완료 기준` 질문에 막힘없이 답할 수 있어야 그 과목이 끝난 것이다.
