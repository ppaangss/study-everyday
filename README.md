# study-everyday

백엔드 개발을 공부하면서 정리한 노트를 모아둡니다.

## 구성

주제별 디렉토리로 나누고, 그 안에서 다시 세부 주제로 나눕니다.

```
study-everyday/
├── java/
│   ├── 컬렉션/
│   └── 동시성/
├── spring/
├── database/
└── ...
```

주제가 늘어나면 디렉토리를 추가합니다.

## 쓰는 방식

- 읽은 내용을 요약하지 않고, **이해한 것을 내 말로** 다시 씁니다.
- 개념만 적지 않고 **직접 확인한 것**(재현한 문제, 측정한 수치, 실행한 명령)을 함께 남깁니다.
- 나중에 다시 읽었을 때 그때의 이해가 복원되는 것이 목표입니다.
- 틀린 내용을 발견하면 지우지 않고 고친 이유와 함께 갱신합니다.

## 진행 중

꾸준히 채워나가는 중입니다.
